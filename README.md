# server-tooling

Scripts for deploying, monitoring and maintaining the servers and their services.

## Update to the latest

To update everything — this repo, [mac-tooling](https://github.com/mwagstaff/mac-tooling), its shell config and CLI tools — in one go:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/mwagstaff/mac-tooling/main/update.sh)"
```

To update just this repo manually:

```bash
git -C ~/dev/server-tooling pull --ff-only
```

Not cloned yet:

```bash
git clone https://github.com/mwagstaff/server-tooling.git ~/dev/server-tooling
```
